How Importance is Derived

Asked directly, customers say everything is important. Ranking nine hypothetical systems forces tradeoffs. Chain: rankings → attribute scores → normalized 0–1 values (App. 4.1) → range per attribute → importance %. *Rounded so the four sum to 100 (price is exactly 33.3%).
