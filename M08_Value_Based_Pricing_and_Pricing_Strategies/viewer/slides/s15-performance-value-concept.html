Performance Value Pricing: Concept
Module 4's conjoint preference curves, now used to test whether a price premium is defensible
From Module 4

Same method as Ch. 4: preference curves → sum → compare. The value score is the CVI from Module 4. Here the competitor comparison is explicit, and price is one of the scored attributes.

When to Use

Use performance-based pricing when customers cannot easily quantify total cost of ownership — but can evaluate relative product attributes (trim, finish, quality, service).

Step 1 — Read the Curves

Each attribute level, price included, has a 0–1 preference value. A curve's range reflects its importance (the % in the chart title), so the weights are already built in.

Step 2 — Sum to a Value Score

Add the curve values for the company and for the competitor.

Step 3 — Compare

Value advantage % = (company − competitor) ÷ competitor. A premium is defensible while the price premium % stays below it.

Critical Insight

The same product can have a value advantage with one segment and a value deficiency with another — if the segments differ in importance. The value driver changes too: performance for quality-conscious buyers, price for price-sensitive buyers.
